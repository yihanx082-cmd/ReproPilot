# 访谈记录规则

这个目录只存放已经匿名化、得到同意的研究记录。原始聊天、真实姓名和联系方式不进入 GitHub。

## 参与者编号

固定使用 P01、P02、P03、P04、P05。每位参与者对应一个文件，例如 `P01.md`。在对方真实回复到达前不要创建参与者文件，也不要填充示例回答，以免示例被误认为真实证据。

## 单份记录结构

```markdown
# P01 访谈记录

- 同意状态：已同意
- 访谈方式：异步文字
- 第一轮日期：YYYY-MM-DD
- 第二轮日期：YYYY-MM-DD
- 相关经验：对方自己描述的宽泛背景

## 第一轮原始回答（已去身份化）

### Q1
> 保留原意的回答

## 第二轮原始回答（已去身份化）

### Follow-up 1
> 保留原意的回答

## 研究者概括

- 事实：可以直接追溯到回答的内容
- 解释：研究者对事实的理解
- 假设：仍需其他参与者或测试验证

## 可用于汇总的证据

| 证据编号 | 类型 | 内容 | 原始回答位置 |
|---|---|---|---|
| P01-E01 | 阻塞/耗时/人工步骤/判断标准 | 去身份化摘要 | 第一轮 Q4 |
```

## 数据边界

禁止提交：真实姓名、邮箱、学校或公司全称、手机号、API Key、账号、私有仓库 URL、未公开数据、绝对路径、访问令牌以及能重新识别参与者的组合信息。

允许提交：得到同意的去身份化回答、宽泛经验背景、时间区间、操作步骤、问题类型和判断依据。

如果对方撤回同意，从 Git 历史中彻底移除会比较困难，因此首次提交前必须再次确认内容已经去身份化且允许进入公开作品集。
