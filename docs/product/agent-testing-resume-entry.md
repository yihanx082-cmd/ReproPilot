# ReproPilot｜Agent 测试实习岗位简历版

## 推荐版（直接粘贴到简历）

**项目名称：ReproPilot——机器学习论文复现与代码修复 Agent**　　**独立开发 / Agent 测试**　　**2026.08–至今**

**技术栈：** Python、Pytest、Docker、Git、Pydantic、DeepSeek / OpenAI Compatible API、React、GitHub Actions

**项目简介：** 面向机器学习论文复现的代码执行与修复 Agent，将论文证据抽取、论文与代码配置审计、Docker 隔离运行、错误诊断、最小补丁、测试回滚、实验对比和可信度评分串成可审计状态机；围绕 Agent 的错误定位、修复正确性、语义安全、代码副作用和运行成本建立故障注入评测体系。

- **故障定位能力优化：** 将故障细分为依赖、路径、配置、指标、CUDA/运行时和数据处理等类型，结合错误日志、退出码、语义要求与仓库上下文缩小检索范围；在 3 个仓库、6 个冻结案例的真实模型评测中实现错误定位 `6/6`，减少 Agent 在无关文件中的搜索与修改。
- **修复性能提升：** 通过“诊断 → 最小补丁 → 目标测试 → 语义探针 → 继续运行”的反馈循环增强 Agent 自我纠错能力，在不知道注入补丁和逆向 Git diff 的条件下实现修复成功 `6/6`、修复后探针通过 `6/6`、无关代码修改率 `0%`，平均补丁尝试 `1.0` 次。
- **修复鲁棒性优化：** 不以补丁成功应用或进程退出码作为最终结果，而是联合 Git diff、目标测试、语义探针、最小运行和工作区哈希进行多层判定；补丁验证失败时自动回滚并进入下一轮诊断，避免错误补丁污染后续上下文。
- **高风险安全测试：** 将数据划分、评价指标、模型结构和 checkpoint 修改标记为语义高风险，要求人工审批且与补丁 SHA-256 绑定；补丁内容变化后旧审批自动失效，验证失败时反向应用补丁并校验工作区恢复，覆盖 Agent 越权修改和失败污染场景。
- **端到端场景验证：** 在 ResNet-20/CIFAR-10 真实案例中复现 CPU/CUDA 兼容错误和 checkpoint 元数据缺失问题，验证首次补丁失败后的精确回滚与二次修复；执行 3 个显式种子的独立评估，得到 Error `8.27%` 对论文 `8.75%`，系统基于 7 个证据维度输出 `80/100 PARTIAL`，明确区分“程序跑通”与“完整复现”。
- **性能评测与可观测性：** 建立覆盖定位正确率、修复成功率、语义探针通过率、无关修改率、补丁尝试次数、工具调用和 Token 成本的 Agent 指标体系；交付快照包含 `164` 项 Python 测试，其中 `4` 项为需 Docker Engine 的集成案例，并记录 6 次模型调用、`18,846` tokens、54 次工具调用和 `54.35s` Agent 墙钟时间，为后续模型与策略对比提供可复现基线。
