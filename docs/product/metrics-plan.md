# ReproPilot 产品指标方案

## 为什么要分成两类指标

工程指标回答“智能体修得准不准、代价多大”，产品指标回答“用户是否更快、更少操作并且正确理解结果”。两者不能互相替代：修复测试通过不代表用户信任产品，满意度高也不代表复现结论正确。

## 产品指标

| Metric | 中文含义 | 精确定义 | 数据来源 | 解释与限制 |
|---|---|---|---|---|
| Task completion rate | 任务完成率 | 无主持人介入完成五个指定任务的人数 ÷ 开始测试人数 | 观察表中的 T1–T5 与介入记录 | 小样本报告为 `4/5` 等人数，不外推总体 |
| Time to interpret | 理解当前状态用时 | 从展示执行时间线开始，到参与者正确说出“当前阶段、暂停原因、下一步动作”的秒数 | 录屏或主持人时间戳 | 只比较相同任务和相同原型版本 |
| Manual steps reduced | 人工步骤减少量 | 同一任务定义下，人工基线的离散操作数 − ReproPilot 辅助流程操作数 | 基线操作清单与原型事件记录 | 先定义“一个步骤”，鼠标移动不计步骤 |
| Decision correctness | 决策正确率 | 正确识别高风险原因并作出与任务规则一致决定的人数 ÷ 参与人数 | T3、T4 回答与决策 | 不以是否点击“批准”判断，理由必须正确 |
| Report comprehension | 报告理解率 | 能解释 `PARTIAL`、分数依据、未解决风险，且明确 credibility score 不是 model accuracy 的人数 ÷ 参与人数 | T5 复述 | 必须记录原话或忠实摘要 |
| Satisfaction | 满意度 | 完成任务后的 1–5 分评分，并附一条必填理由 | 测试后问卷 | 不把均值单独作为成功结论，保留范围和理由 |

### 操作步骤的统一定义

一个人工步骤是用户为了推进复现而执行的一次有意图的操作，例如修改配置、执行命令、搜索报错、查看日志、比较指标或请求帮助。连续输入同一条命令算一步；等待训练不算步骤，但单独计入总时间。

### 建议记录格式

| participant_id | prototype_version | completed_without_help | time_to_interpret_seconds | baseline_steps | assisted_steps | decision_correct | report_comprehension | satisfaction_1_to_5 | reason |

## 工程指标

| 指标 | 公式或取值 | 当前证据 |
|---|---|---|
| 错误定位率 | 正确定位故障案例数 ÷ 总案例数 | 真实 Agent 基线 6/6 |
| 修复成功率 | 补丁通过语义探针的案例数 ÷ 总案例数 | 真实 Agent 基线 6/6 |
| 修复后测试通过率 | 修复后探针通过数 ÷ 已修复案例数 | 真实 Agent 基线 6/6 |
| 无关代码修改率 | 与目标故障无关的改动数 ÷ 全部改动数 | 真实 Agent 基线 0% |
| 运行成本 | 模型调用、输入/输出 token、工具调用、墙钟时间和可获得的美元估算 | 6 次模型调用、18,846 tokens、54 次工具调用、约 54 秒 Agent 时间 |
| 结果接近程度 | 论文指标与多随机种子观测均值的差值 | Error 8.27% 对论文 8.75%，差 -0.48 个百分点 |

工程基线只覆盖 3 个仓库、6 个单故障案例；语义探针通过不等于完成整篇论文训练。

## 探索性对照方案

为每位参与者提供同一份已去敏的任务材料。先让其根据人工材料判断运行状态和可信度，再使用 ReproPilot 原型完成相同判断。记录总时间、操作步骤、是否求助和答案正确性。为了减少学习效应，五人中交替安排“人工优先”和“原型优先”，并在报告中保留顺序。

样本只有五人，因此只报告人数、median（中位数）、range（范围）和去身份化理由，不做显著性检验，不写“提升了所有用户”等总体结论。

## 数据完整性规则

- 测试前锁定任务定义和原型版本；
- 主持人介入必须记录时间和内容；
- 没有发生的测试保留为等待状态，不能填入估算值；
- 产品指标与工程指标在图表和叙述中分开展示；
- 任何百分比同时展示分子和分母。

## 第一轮产品指标观测

| 指标 | 观测 | 是否达到门槛 |
|---|---:|---|
| Task completion rate（含提示） | 5/5 | 仅说明路径可完成 |
| Task completion rate（无帮助） | 3/5 | 否，目标为至少 4/5 |
| Report comprehension（首次不误解分数） | 3/5 | 否，2/5 曾误认为准确率 |
| 三项未解决风险完整识别 | 2/5 | 未设硬门槛，需改善信息层级 |
| Satisfaction | 均值 3.8/5，范围 3–5 | 探索性描述 |
| Time to interpret | 未记录 | 不估算 |
| Manual steps reduced | 无统一基线 | 不声称改善 |

五人样本只用于发现问题和验证交互，不做显著性检验，也不外推到目标用户总体。
