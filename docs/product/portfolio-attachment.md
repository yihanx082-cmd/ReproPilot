# ReproPilot AI 产品经理作品附件

> 版本：2026-09-15｜独立项目｜GitHub：yihanx082-cmd

## 01 项目概览

ReproPilot 是一个面向机器学习论文复现的代码执行与修复智能体。它接收论文 PDF、代码仓库、数据集与环境信息，在受限 Docker 环境中完成论文与代码对齐、最小运行、错误诊断、补丁验证、实验结果比较，并生成带证据边界的复现可信度报告。

这个项目关注的不是“模型能否回答论文内容”，而是“项目是否真的跑通，以及结果是否足以支持复现结论”。

## 02 用户问题与产品机会

论文复现者需要在论文、README、配置文件、终端日志、代码 diff 和实验结果之间反复切换。显式报错只是其中一类问题；更危险的是代码成功运行，但数据划分、指标口径或 checkpoint 已经偏离论文。

目标用户是有基础 Python 或机器学习经验的学生、研究人员与 ML 工程师。第一轮 5 位真实参与者中，环境与依赖、数据与指标对齐、checkpoint 来源都是反复出现的问题。

## 03 产品方案

核心流程：论文证据解析 → 代码配置审计 → Docker 构建 → 最小运行 → 错误诊断 → 最小补丁 → 测试/审批 → 正式实验 → 论文对比 → 可信度报告。

设计原则：让大模型只负责论文声明抽取和补丁建议；命令策略、风险判断、Git 事务、评分和状态转换由确定性代码控制。

## 04 关键机制

- 原仓库和数据集只读，修改只进入工作副本；
- 每次修改保存 Git diff、日志、测试结果和 artifact 引用；
- 数据、指标、模型、权重等语义修改必须人工审批；
- 审批与补丁 SHA-256 绑定，补丁变化后旧批准失效；
- 测试失败时精确回滚；
- 缩小实验不能被标记为完整复现。

## 05 真实复现实验

ResNet-20/CIFAR-10 案例从论文 PDF、旧仓库和公开 checkpoint 开始。系统修复了 CPU/CUDA 兼容问题和 checkpoint 元数据缺失问题，并执行三个显式种子的评估。

- 论文报告 Error：8.75%
- 观测 Error：8.27 ± 0.00%
- 差值：-0.48 个百分点
- 证据可信度：80/100，PARTIAL

80/100 不是模型准确率。结果使用公开 checkpoint 重复评估，并非三次从头训练，因此只能作为部分复现证据。

## 06 Agent 评测

评测清单覆盖 5 个固定开源仓库、8 个单故障案例。已发布的模型基线覆盖其中原始 3 个仓库、6 个案例：6/6 定位正确、6/6 修复成功、6/6 修复后语义探针通过，无关改动率 0%，共 6 次模型调用、18,846 tokens、54 次工具调用，Agent 墙钟时间约 54 秒。

新增两个仓库只完成了确定性注入与探针验证，尚未计入模型成绩。6/6 不能外推为 8/8 或通用成功率。

## 07 用户研究与迭代

第一轮 5 位真实参与者均完成核心流程，但只有 3/5 无帮助独立完成；2/5 初次把可信度分数误认为模型准确率，只有 2/5 完整指出三项未解决风险，满意度均值为 3.8/5。

这轮测试未达到“至少 4/5 独立完成”的门槛。基于观察证据，第二版完成三项关键修改：

1. 永久显示“证据可信度，不是模型准确率”；
2. 审批页增加数值样例、论文引用、断言、退出码和日志；
3. 拒绝补丁后状态从 VERIFIED 修正为 STOPPED - PATCH REJECTED。

## 08 产品定位

Papers with Code 更适合论文与代码发现，Code Ocean 更擅长封装和重复运行，通用 Coding Agent 更擅长仓库任务。ReproPilot 的窄差异是：接手一个可能已经损坏或与论文不一致的项目，从配置审计和受控修复开始，最后生成论文级结果对比与可追溯的可信度判断。

## 09 个人贡献

独立完成产品问题定义、竞品研究、PRD、状态机与证据模型、Python CLI、Docker 沙箱、修复与回滚机制、可信度评分、HTML 报告、React 原型、真实项目评测、用户访谈、可用性测试和迭代。

技术栈：Python、Pydantic、Docker、Git、pytest、React、Vite、OpenAI 兼容 API、GitHub Actions。

## 10 当前边界与下一步

当前已经形成作品集级 MVP，但不能包装成生产级科研平台。工程侧已增加单轮、结构化诊断、反馈循环和跨任务验证记忆四组消融框架，用于量化 Agent 机制的真实贡献；在新凭据下完成三重复真实模型实验前，不发布预设提升数字。仍需由项目所有者完成第二轮真人复测、录制本人讲解视频，以及在未来真实从头训练案例中验证训练过程复现。
