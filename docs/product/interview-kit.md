# ReproPilot 异步用户访谈手册

## 研究目的

了解有论文复现经验的人实际如何开始、在哪些地方受阻、怎样判断“复现成功”，再用真实证据检验 ReproPilot 的产品假设。本轮只记录经历，不推销产品，也不把受访者的愿望直接当成需求。

## 可直接发送的邀请文字

> 你好，我正在做一个机器学习论文复现工具的产品研究。想请你回忆最近一次真实的论文复现经历，通过两轮文字消息回答问题，每轮大约 10–15 分钟，不需要语音或视频。内容只用于作品集研究，我会用 P01–P05 代替姓名，不公开学校、单位、仓库权限或其他敏感信息。你可以跳过任何问题，也可以随时退出。愿意参加吗？

## Consent

只有对方明确回复愿意后才开始记录。开始前确认以下四点：

1. 回答将用于 ReproPilot 产品研究和匿名作品集；
2. 原话可能以去身份化的短句呈现；
3. 对方可以要求删去任意回答或退出；
4. 不收集 API Key、私有代码、未公开论文数据、真实数据路径或账号信息。

把同意状态记录为“已同意”或“未同意”，不要保存对方的真实姓名到仓库。

## Round One：最近一次真实经历

请一次发送 3–4 个问题，等对方回答后再继续，避免一大段问题造成负担。

1. 请回忆你最近一次复现机器学习论文：你想复现哪类结果，最后做到了什么程度？
2. 你从拿到论文和代码开始，按顺序做了哪些事情？
3. 整个过程大约花了多久？其中哪些阶段最耗时？
4. 第一个阻塞你的问题是什么？你当时怎样判断原因？
5. 你遇到过论文描述与代码默认配置不一致吗？当时怎样决定相信哪一边？
6. 你使用了哪些工具或资料，例如 README、issue、搜索、调试器或大模型？哪个最有帮助？
7. 哪些步骤必须由你手工完成？有没有请别人帮忙？
8. 什么情况会让你暂停或放弃一次复现？
9. 你最终用什么标准判断“复现成功”“部分成功”或“失败”？

### 访谈者记录

- 开始和结束时间；
- 对方主动提到的工具、人工步骤和阻塞；
- 可量化信息，例如小时数、重跑次数、求助次数；
- 需要在第二轮确认的歧义；
- 不要在这一轮展示 ReproPilot 原型。

## Round Two：基于回答追问

第二轮必须引用第一轮的具体内容。不要机械地把所有追问都发给每个人。

- 你提到“___”最耗时，能否把那一步拆成实际操作？
- 当时你看到了哪些证据，才认为根因是“___”？
- 如果没有“___”工具或同学帮助，你预计还要多花多久？
- 论文和代码冲突时，你最后采用了“___”，这个决定有多大把握？
- 哪一步出错最可能产生“代码能跑，但结果不可信”的情况？
- 如果系统自动改了数据划分、指标或模型，你希望批准前看到什么？
- 假设只保留一个结果页面，哪些证据必须出现，才能让你信任结论？
- 我把你的经历概括为“___”。这个理解准确吗？哪里需要修正？

## Anonymization

- 依次使用 P01、P02、P03、P04、P05，不用姓名、昵称或邮箱；
- 学校、公司和实验室统一改为“某高校”“某团队”或“某公司”；
- 私有仓库改为“私有图像分类仓库”等功能描述；
- 绝对路径、用户名、数据下载地址和凭据全部删除；
- 引用原话前先去除可识别细节，不改变原意；
- 原始聊天只保存在用户自己的聊天工具中，不提交 GitHub。

## 访谈纪律

- 问“最近一次怎么做”，不问“你想要什么功能”；
- 允许沉默和不确定答案，不替对方补充；
- 追问事实、动作和判断依据，不与对方争论技术方案；
- 明确区分原话、研究者概括和未经验证的产品假设；
- 五人全部完成前也可以总结阶段性观察，但必须标明样本数。
