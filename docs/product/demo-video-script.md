# ReproPilot 5 分钟演示视频脚本

目标时长：4 分 30 秒至 5 分钟。录制时使用本地可点击原型和真实仓库文件，不展示 API Key、私人路径或参与者身份。

## 0:00–0:30｜问题

画面：标题页与完整流程图。

旁白：复现机器学习论文并不等于把代码跑通。论文参数、数据划分、指标口径和代码实现只要有一项不一致，就可能得到看似合理但不可比较的结果。ReproPilot 的目标是让整个复现过程可执行、可修复，也可审查。

## 0:30–1:10｜创建任务

画面：Task Creation，依次指向论文、仓库、数据集、环境和运行范围。

旁白：用户提供论文 PDF、GitHub 或本地仓库、目标数据集与环境信息。系统先建立任务范围，而不是立刻运行任意命令。本次演示使用 ResNet-20 和 CIFAR-10 的去敏冻结数据，页面本身不会真正启动训练。

操作：点击 `Review scope`。

## 1:10–1:50｜论文—代码对齐

画面：Scope Review，展示论文声明、代码事实和 mismatch。

旁白：系统把论文声明和代码事实并排展示，并保留页码、文件和行号证据。例如学习率、数据划分或指标实现不一致时，用户在运行前就能看到影响。本次是缩小复现，不宣称覆盖论文的完整训练预算。

操作：点击 `Start reproduction`。

## 1:50–2:40｜执行时间线

画面：Execution Timeline，点击不同阶段。

旁白：左侧是状态机阶段，中间解释当前事件，右侧给出命令、日志、diff、测试和 artifact。这个结构同时回答三个问题：正在做什么、为什么这样做、凭什么相信结论。真实 Agent 评测覆盖 3 个仓库和 6 个单故障案例，完成 6/6 定位和 6/6 修复后语义探针，当前证据不外推到任意论文。

## 2:40–3:30｜高风险补丁审批

画面：Approval，突出 SHA、diff、语义影响和测试。

旁白：普通依赖或路径修复可以自动验证，但数据、指标、模型和预训练权重修改可能改变实验含义，因此必须暂停。批准记录绑定补丁 SHA；diff 一旦变化，旧决定失效。这里展示的是指标口径修改的交互示例。

操作：点击 `Approve patch`，返回时间线后打开报告。

## 3:30–4:30｜可信度报告

画面：Credibility Report，依次指向 80/100、PARTIAL、论文值、观测值和限制。

旁白：最终结果不是一句“复现成功”，而是 80/100、PARTIAL。This is not model accuracy；它是环境、数据、配置、指标、随机种子、结果接近程度和外部依赖七个维度的证据可信度。论文 Error 是 8.75%，公开 checkpoint 的观测值是 8.27%，差 -0.48 个百分点。但这不是三随机种子从头训练，所以只能判为部分复现。

## 4:30–5:00｜证据边界与下一步

画面：工程指标表、用户研究等待状态、Git diff/测试记录。

旁白：这个项目已经验证了 Agent 执行闭环和可点击产品流程，但真实用户指标仍是 Awaiting real participant responses。下一步是访谈 5 位有复现经验的用户，测量完成率、理解时间、人工步骤和报告理解率，再决定是否把 Web 原型连接真实 CLI。整个案例保留 Git diff、测试和限制，让作品集结论也可以被审查。

## 录制检查

- 画面中没有 API Key、用户名、私人目录或真实参与者信息；
- 不把 fixture 描述成实时训练；
- 不把 6/6 描述成通用成功率；
- 不把 `80/100` 描述成模型准确率；
- 结尾展示 GitHub 仓库、测试结果与下一步研究状态。
